# StudyApp 0.1.0 · 本地首版

Windows 10/11 x64 原生中文应用，采用 GPUI Kit 0.7.3。

- 导入 UTF-8 Markdown、搜索和只读预览，记录内容快照、版本差异与离线变更。
- 运行时学习计时、暂停、定时询问、超时结算、手动补记和记录更正。
- 默认 1/3/7/14/30 天间隔复习、逾期待办、勾选完成与撤销。
- 本地日历统计、SQLite 持久保存、资料库切换、一致性备份与验证恢复。
- CI 检查业务规则和原生窗口，发布包附 SHA256、MIT LICENSE 和第三方通知。

此版本未进行代码签名，没有自动更新器。微信登录、云端与双端同步尚未配置，当前只支持本地存储。学习时长由用户确认，应用不会自动证明实际专注；关闭/休眠期间不累计。文件轮询和防抖各为 3 秒，无法追溯应用关闭期间的每次编辑；Markdown 图片和链接保持禁用。

请在升级前用「设置 → 导出备份」保存资料。ZIP 免安装，默认资料位置为 `%APPDATA%\StudyApp\StudyApp\data`；数据库和备份未加密，包含笔记快照及本机路径。备份不复制原始 Markdown，换电脑请另行复制并重新关联。
