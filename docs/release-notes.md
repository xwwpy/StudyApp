# WW-StudyApp 0.6.0 · 紧凑工作区与分类配置

笔记库将目录树、笔记列表和正文并排显示，侧栏宽度与导航显隐按资料库保存；拖动、确认操作和结果提示使用更清晰的交互反馈。

- 默认导航、目录和列表宽度缩小到 160 / 144 / 200 像素。拖动分隔条只显示虚线位置，正文保持可见，松手才应用尺寸；Esc、失去焦点或鼠标捕获取消。主导航和目录栏均可拖至各自左缘隐藏，顶部的侧栏图标可快速隐藏或恢复。
- 目录树和笔记列表独立滚动，目录层级、选中状态和分区标题更清楚。正文较窄时，变更历史使用上方可横向滚动的版本条，差异正文继续独立滚动。
- 拖动笔记时，紧凑预览保持在指针附近，长标题收纳在卡片内；从条目右下角开始拖动也保持相近的预览距离。有效目录和「未分类」仍在悬停时突出显示。
- 目录操作表单、按钮发起的笔记移动，以及取消管理、删除草稿和逐份清理托管副本的确认，集中在弹窗中处理。弹窗内容在限定高度内滚动，Tab / Shift+Tab 在弹窗内切换焦点，Esc 取消返回；背景操作暂时阻止。新建和重命名目录继续支持 Enter 提交，保留名称校验、重复提交与过期动作检查。
- 操作结果与临时错误在整个窗口顶部水平居中，确认弹窗在窗口中居中；侧栏显隐不影响提示位置。提示可关闭，成功提示自动收起，不改变正文大小或接管输入焦点。
- 可操作的按钮、目录项和菜单使用手形指针，禁用项使用普通箭头，布局分隔条使用水平调宽指针。右键菜单保留「移动到目录」「在文件资源管理器中显示」和「复制文件路径」。
- 目录的重命名、移动、删除空目录和新建子目录移入右键或行尾菜单；目录自身可拖动调整父级。选中目录只绘制一层背景，不改变行尺寸。
- 设置使用 `config` crate 加载，学习、界面、快捷键和同步参数分类保存。页面编辑副本，点击保存才原子发布整套配置；有未保存修改时离页、关闭或执行资料操作，会提示保存、放弃或继续编辑。恢复初始设置生成默认草稿，仍需保存。
- 支持自定义 41 项应用与 Markdown 编辑命令，允许多个组合或取消绑定，保存时校验冲突。重映射保留正文、选区及撤销历史；初始配置文件和历史配置代保留。
- 升级 `rustls-webpki` 至 0.103.16、`webpki-root-certs` 至 1.0.10，修复最新公布的证书信任问题。

分类操作只改变逻辑目录元数据，源文件和历史保留；目录最多八层，同级不能重名，删除目录要求没有笔记或子目录。移动目标继续排除当前目录、自身、子孙目录及超深位置，资料库切换后的过期拖放和菜单动作会被拒绝。已取消管理的笔记仍可调整分类。文件路径默认隐藏，可在设置中开启并保存；右键显示原文件和复制路径始终可用。

目录分类随数据库备份保存；界面等分类设置跟随资料库独立保存。**本版恢复数据库只恢复学习资料，保留当前设置**；完整迁移会复制分类配置。旧版数据库设置与 `sync-config.json` 首次启动时导入，原文件保留。连续 Markdown 编辑、语法高亮、历史和草稿机制沿用现有文档协议；继承 0.5.0 的 Windows 正文绘制与拆分 UTF-16 输入修复，并修复按钮与调宽光标切换的原生延迟。

Windows 10/11 x64，使用 GPUI Kit 0.7.3 和本地 WebView2 编辑面。需 Microsoft Edge WebView2 Runtime；编辑器资源离线打包，普通使用无需 Node.js。发布包名为 `WW-StudyApp-0.6.0-windows-x86_64.zip`，解压后运行 `WW-StudyApp.exe`。已有资料库、配置、同步目录和凭据标识继续沿用，开发构建仍使用 `studyapp.exe`。GPUI Windows 绘制层和组件补丁的完整修改源码、许可证及来源说明随包提供。

沿用 schema 3，兼容读取旧 schema 1/2。默认数据库位置仍为 `%APPDATA%\StudyApp\StudyApp\data\studyapp.sqlite3`，升级前可先导出备份。空间管理仍只允许逐份确认清理托管副本，历史和学习记录保留；外部源文件、未知文件及整个目录不会被删除。

同步只传输最新 Markdown，学习记录、复习计划、目录分类和完整历史仍在本地；微信登录和账户级云端仍为预留接口。ZIP 未代码签名，无自动更新器。测试、原生验收和发布状态以 [验证记录](https://github.com/xwwpy/StudyApp/blob/main/docs/verification.md) 及对应 GitHub Release 为准。
