# StudyApp 0.4.0 · 连续 Markdown 编辑、目录与资料迁移

这次移除段落输入框加重复预览的交互，改为一个连续的 Markdown 编辑面。边写边排版，跨段选择、键盘移动、粘贴、撤销、重做和源码切换共享同一份文档。

- 标题、强调、列表、引用、任务、表格与代码在原位显示；光标所在语法可直接编辑。任务勾选写回 Markdown，并可撤销。
- 离线高亮支持 Rust、Python、JS/TS/JSX/TSX、C/C++、C#、Java、Go、HTML、CSS、JSON、YAML、TOML、SQL、Shell。
- 使用增量解析和可见区域渲染；编辑通知只发送变更。10 MiB 文件限制按真实 UTF-8 和换行字节计算，超限编辑原子拒绝。
- 保存、保留草稿、切库、关闭先确认末次输入。保留/切库/关闭等待草稿真正落盘，失败保留内容；异常桥接状态可显式重试恢复输入。
- 当前草稿和待恢复草稿均可删除，确认后不再恢复；原笔记和历史保留。
- 笔记可取消管理，停止扫描和同步，保留磁盘文件、历史及学习复习记录；再次导入同一路径恢复管理。远端同 ID 不会自动复活已取消管理的笔记。
- 同步进行中阻止取消管理、切库或恢复备份，避免旧上传任务继续写入。
- 历史版本列表与差异正文分别滚动，长差异按可见行渲染、完整保留；历史快照可明确复制后编辑。
- 支持最多 8 层目录、重命名和移动目录/笔记，目录调整不移动跟踪的原始文件。
- 设置中可迁移当前资料库到新的空目录，原库保留，并记住下一次启动位置。迁移前等待编辑器和草稿落盘，失败不切库。
- 新增资料库空间统计及逐份托管副本清理，只删除明确归属当前库的普通文件，外部源文件/链接/目录不可删除。历史仍可导出和复制恢复。
- Windows 路径展示去除 `\\?\` 前缀，文件读写仍使用原规范路径。
- 新增前端类型检查、资源可重复构建/许可证检查、浏览器回归和 npm 审计，作为 CI 与发布必过检查。

Windows 10/11 x64，使用 GPUI Kit 外壳和本地 WebView2 编辑面。需 Microsoft Edge WebView2 Runtime；缺失时安装 Evergreen Runtime。资源随程序离线打包，无需 Node.js。原始 HTML 不执行，远端图片不加载，链接不自动打开；尚不提供图片渲染、公式或 Mermaid 的完整 Typora 功能。

数据库自动升级到 schema 3，读取旧 schema 1/2；旧版应用拒绝打开升级后的资料库。升级前请导出备份。取消管理只影响当前资料库；不会删除本地或远端文件。备份保留取消管理状态且不重建其磁盘文件。

现有学习计时、定时确认、复习、统计、历史、拖放、WebDAV 和本地/NAS 同步继续可用。同步只传输最新 Markdown，学习记录、复习计划及完整历史仍在本地；微信和账户级云端仍为预留接口。ZIP 未代码签名，无自动更新器。实际验证和限制见 [验证记录](https://github.com/xwwpy/StudyApp/blob/main/docs/verification.md)。
