# Markdown 即时编辑

用户要求将现有 Markdown 编辑页改为 Typora 风格的原位编辑和实时预览。沿用用户已给出的持续实施授权，无需再次审核设计。

## 交互

默认采用单栏、段落原位编辑：未编辑的标题、段落、列表、引用、代码块和表格直接呈现排版。点击内容块后，该处展开 Markdown 输入框，并在其下实时呈现当前块效果。切换到另一块或按 Escape 收起源码；Ctrl+Enter 完成本块。末尾提供继续写作入口。中文输入法沿用 GPUI 原生输入组件。

工具栏提供标题、粗体、斜体、列表、引用、代码和表格；对当前选区操作。支持全文源码模式，用于跨段选择和批量编辑，并保留实时预览。编辑模式切换不创建版本、不改变 Markdown 字节。

曾考虑仅增加左右分屏（不能满足原位编辑）和嵌入网页富文本引擎（新增 WebView 运行时和富文本序列化转换风险）。选择原生 GPUI Kit 的块编辑方案，诚实标明其为段落即时编辑，不声称与 Typora 完全一致。

## 数据与安全

Markdown 原文是唯一持久化内容。使用 pulldown-cmark 的源位置划分顶层语法块，完整保留空行、CRLF、中文、代码围栏、表格和引用定义；不经过 HTML 反向序列化。编辑期间固定当前块边界，避免未闭合语法导致输入框重建或丢失焦点。离开当前块后重新分块。

全文与段落编辑共享撤销/重做记录，记录有内存上限。草稿恢复、保存版本、预期哈希冲突检查和资料库隔离保持现有契约。保存中禁止修改。预览继续移除 HTML 活动内容、图片资源请求和可执行链接。

渲染结果按内容变化缓存；只限制预览规模，不能截断保存内容。超过即时排版上限的文档自动进入完整源码编辑，明确显示原因。编辑器自身管理滚动，工具栏保持可见。

实际实现上限：即时布局 256 KiB / 500 块，单块预览 64 KiB / 约 400 行；包含超大单块时也进入源码模式。会话撤销最多 100 个快照、合计 4 MiB，正文超过预算时不保留会话撤销，持久版本不受影响。输入法组合在显式保存、切换段落、保留草稿或切换资料库前同步到原文。

## 验收

- 默认进入即时编辑，点击块、输入、收起、再进入可保持原文和排版。
- 输入后无需切换模式即可看见粗体、标题、列表、代码和表格效果。
- 中文/emoji、CRLF、嵌套列表、多行代码、未闭合围栏、引用链接定义编辑往返不丢字符。
- 全文源码与原位编辑间切换、撤销重做、保留草稿、恢复、保存版本均正常。
- 原生窗口自动化执行上述核心操作并保存截图；工作区测试、fmt、clippy 和 CI 通过。
