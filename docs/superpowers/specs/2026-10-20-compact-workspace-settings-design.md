# 紧凑工作区、延迟拖动与配置草稿

用户在 0.6.0 发布前新增本设计要求。延续其“后续不需要审核，直接完成”的授权；本次不发布旧方案，完成下面两组工作后统一验收。

## 工作区交互

- 默认导航 160px、目录 144px、笔记列表 200px。分隔条视觉线宽 1px，保留约 6px 命中范围；用户已经调整的偏好不得无条件覆盖。
- 主导航收展按钮放在左上角固定工具区域，使用侧栏图标及悬停文字；目录收展按钮放在笔记工作区左上角，隐藏后仍可见。目录与导航均可拖到各自左侧边界收起，再由图标恢复之前宽度。
- 拖动分隔条只更新候选宽度和虚线；鼠标释放时才改变布局并保存，Esc 或失去拖动状态取消。正文 HWND、内容、选区和视口在拖动期间保持可见、稳定。跨越正文的虚线必须使用可显示在 WebView 子窗口之上的非激活透明原生覆盖层。
- 笔记/目录的归属移动只在合法落点释放时提交；悬停只展示边界。目录右键菜单提供新建子目录、重命名、移动到目录、删除空目录，删除仍使用确认弹窗。拖动目录复用核心父子关系与八层限制，排除自身、后代和当前父级。未分类是回到顶层的目标。
- 目录选中状态仅有一层背景/边框，不再叠加组件 selected 背景。移除选中目录后出现的底部操作区，避免列表跳动。
- 结果通知始终按整个窗口水平居中，确认弹窗按整个窗口水平及垂直居中。通知不抢焦点，成功自动收起、错误保留关闭按钮，正文区域不因提示改变。

采用“候选布局 + 释放提交”，而非每帧重排或隐藏编辑器截图替代。额外的原生虚线覆盖层用于解决 GPUI 主窗口绘制无法覆盖 WebView 子 HWND 的实际限制。

## 配置与快捷键

- 使用 `config` crate 0.15.27 的 JSON 文件源读取配置。按学习、界面、快捷键、同步分类保存为独立 JSON；只在一次显式保存成功后切换完整配置版本。
- 配置位于当前资料库内。保存先校验并准备全部数据（含 DPAPI 密文），写入完整新代目录，最后原子替换 manifest。manifest 是提交点；提交前失败保留已生效版本，禁止部分设置生效。
- 首次迁移读取现有数据库设置和同步设置，原文件保留。启动加载 manifest 指定配置，数据库中的设置仅作为运行和备份镜像；迁移资料库时包含分类配置。同步运行状态/基线与用户配置分离，目标身份不匹配时不得复用旧基线。
- 内置初始配置随源码和程序保存，资料库也保留默认文件。重置恢复出厂默认到当前草稿，仍需保存才写入。默认文件不含用户密码。
- 进入设置页时保留已加载配置快照，并建立可编辑副本。所有参数编辑（学习间隔、路径显示、布局、同步和快捷键）只改草稿。保存成功后更新快照；保存失败保留草稿并提示。
- 有未保存修改时离开设置页、打开笔记/新建笔记、切换资料库或关闭应用，显示“保存并继续 / 放弃修改 / 继续编辑”。常规设置输入在失败时不能被后台轮询覆盖。
- 数据迁移、备份恢复、清理副本属于显式执行的资料操作；执行前先解决未保存配置，不把数据删除或迁移本身当作可撤销设置。
- 恢复数据库备份保留当前独立配置，只恢复学习资料；界面和文档明确此语义。迁移整个资料库仍携带分类配置和同步凭据。
- 快捷键提供按动作分类的可编辑列表、冲突和非法组合校验、清空绑定及恢复默认。所有应用注册的操作快捷键，以及编辑器格式、保存、撤销重做等命令统一使用保存后的映射。Windows 的窗口切换及输入法系统热键不接管。普通文本移动和输入按编辑器语义保留。
- 编辑器使用可重配 keymap，不因快捷键变化重建正文或撤销历史；原生输入区与 WebView 使用同一映射，不能触发两次或保留已改掉的旧绑定。

分类文件采用配置代和 manifest，而非分别覆盖活动文件，避免学习设置保存成功而同步设置保存失败的半提交。运行镜像在提交后以内存操作更新，启动可从已提交配置重放。

## 验证

先验证旧行为与新期望的差异，再覆盖：拖动中宽度不变/正文可见/虚线位置、释放和取消、两侧栏收展持久化、目录右键与拖动循环拒绝、选中不改变树尺寸、通知和弹窗中心坐标；配置旧版迁移、各类文件加载、重启、无保存不写文件、提交失败、默认恢复、跨库隔离、保存/放弃/继续分支；新旧快捷键、冲突、禁用和编辑器撤销保持。

保持现有学习记录、版本历史、同步和资料安全回归。禁止批量删除或递归删除，不终止用户程序。全部验证完成后提交、CI、发布及下载验证。
