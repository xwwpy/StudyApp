# StudyApp 0.2.1 · 笔记编辑与自有存储同步

Windows 10/11 x64 原生中文应用，采用 GPUI Kit 0.7.3。本地优先，无需 StudyApp 账户。

0.2.1 修正了文件阻塞恢复测试对 Windows 错误类型的假设，使 Linux 的提前拒绝与 Windows 的持久日志恢复分别得到正确验证；笔记编辑与同步功能延续 0.2.0 的实现。

- 新建和编辑托管 Markdown、预览、Ctrl+S 保存不可变版本；保存冲突保留草稿，支持另存新笔记。导入的外部原文件只读，可复制后编辑。
- 多文件拖入及有深度、数量限制的目录导入；搜索最新正文、查看创建/修改/学习日期、按日期筛选学习记录、导出 Markdown 快照到新文件。
- 草稿后台自动保存，每个资料库独立恢复；正常关闭刷新待写内容，恢复前不会用新草稿覆盖已有内容。
- 可配置 HTTPS WebDAV 或文件夹 / 兼容 NAS，测试连接、手动同步和可选 5–1440 分钟自动同步。双方修改时保留冲突副本，不传播删除。
- WebDAV 使用强 ETag 条件写入及 create-only 新建，拒绝无条件覆盖、重定向和无效 TLS；密码由 Windows 当前用户 DPAPI 保护，不进入 SQLite 或备份。
- 保留学习计时、暂停、定时确认、手动补记、记录更正、间隔复习、日历统计、资料库切换与一致性备份。Windows / Linux CI 测试学习核心与同步库，Windows 继续运行工作区检查及原生窗口冒烟。

**同步只传输最新 Markdown。** 学习记录、复习数据和完整版本历史仍在本地 SQLite，通过「导出备份」保存。远端更新不自动记为学习；外部源文件不会被同步改写。主资料库的托管写入及恢复需要硬链接，建议本地 NTFS；NAS 同步目标还须支持文件锁与文件替换，替换前在 `.retained` 保留原文和暂存内容。普通文件夹的锁不能保证不遵守锁的第三方编辑器之间的原子竞争安全；详细要求见 [同步指南](https://github.com/xwwpy/StudyApp/blob/main/docs/sync-guide.md)。真实 WebDAV 服务商和 NAS 环境仍需各自验证，不能由回环测试推定全部兼容。

升级前请先导出备份。0.1.0 资料库会进行兼容迁移；恢复托管笔记时使用当前资料库目录。备份不包含外部原始 Markdown、编辑草稿、同步配置、基线或 DPAPI 凭据，换电脑请复制外部文件并重新配置同步。

ZIP 免安装，默认资料位置为 `%APPDATA%\StudyApp\StudyApp\data`。数据库、备份和笔记文件没有应用级加密，包含正文与本机路径；DPAPI 只保护 WebDAV 密码。异常退出可能损失最后约 650 毫秒的草稿输入或数秒计时。运行时文件轮询与稳定防抖各约 3 秒，不能追溯关闭期间每次保存。

此版本未进行代码签名，没有自动更新器。微信登录和账户级全量云服务仍为预留接口；自有存储同步不等于接入微信或 StudyApp 云后端。Markdown 预览不执行脚本、不加载远端图片或打开链接。具体已执行检查见 [验证记录](https://github.com/xwwpy/StudyApp/blob/main/docs/verification.md)；工作流定义本身不代表已在 GitHub 成功运行。
