# StudyApp Implementation Plan

> **For agentic workers:** Use subagent-driven-development for the core implementation and independent review. User authorized continuous execution without additional review prompts.

**Goal:** Deliver a working Windows GPUI Kit local learning app, tested and versioned on GitHub with CI and release automation.

**Architecture:** A `studyapp-core` library owns all rules, SQLite persistence and file snapshots. A background worker owns the engine and sends immutable view snapshots to a `studyapp-desktop` GPUI window. UI commands cross a typed channel, so filesystem/database operations never block rendering.

**Tech Stack:** Rust 2024, GPUI Kit 0.7.3, SQLite/rusqlite, chrono, serde, uuid, SHA-256, similar, native file dialogs.

## Global Constraints

- Windows 10/11 x64 原生桌面应用，中文界面，使用 gpui-kit 0.7.3。
- No bulk deletion. Never remove source notes or user data directories.
- Local mode must work without authentication. Cloud and WeChat remain explicitly unavailable extension points in this phase.
- UTC persistence, local-calendar presentation. No learned time inferred solely from file edits.
- Commit Cargo.lock. No user databases, notes, personal paths or secrets in Git.
- All runtime failures must be surfaced; report only executed checks as passing.

## Task 1: Persistent learning engine

Files: `crates/studyapp-core/Cargo.toml`, `src/{lib,model,engine,storage,notes,stats,integration}.rs`, `tests/workflows.rs`.

Consumes: the contracts in `docs/superpowers/plans/core-contract.md`.
Produces: `Engine::open`, `Engine::snapshot`, `Engine::tick`, `Engine::apply`, models and commands documented there.

- [ ] Write workflow tests using temporary SQLite databases and Markdown files: reimport deduplication; reload; timeout; pause/restart/gaps; file diff; offline change; complete/undo; corrected summaries; invalid settings; backup/restore; local-calendar totals.
- [ ] Run `cargo test -p studyapp-core` and record expected missing-behavior failures before implementation.
- [ ] Implement validated models, migrations, transactional persistence, bounded UTF-8 reads and immutable snapshots. Implement injectable clock ticks without relying on real sleeps.
- [ ] Run `cargo test -p studyapp-core` and `cargo clippy -p studyapp-core --all-targets -- -D warnings`.
- [ ] Review behavior against the design and commit only owned core files.

Example critical behavioral assertion:

```rust
let mut engine = Engine::open(&db_path, 1_000)?;
engine.apply(Command::SaveSettings(Settings { interval_minutes: 5, ..Default::default() }), 1_000)?;
for second in 1..=300 { engine.tick(1_000 + second, 1)?; }
assert_eq!(engine.snapshot().sessions[0].status, SessionStatus::Pending);
engine.tick(1_600, 0)?;
assert_eq!(engine.snapshot().sessions[0].status, SessionStatus::Missed);
```
