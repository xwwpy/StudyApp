# WW-StudyApp 0.6.0 · 统一笔记库与编辑交互

笔记库与编辑页采用精简菜单，支持点击正文直接编辑、主题预设和自定义外观；新增完整的 Markdown 图片读取、托管和云端存储流程。

- 新增应用自绘标题栏，合并页面标题与窗口控制，侧栏开关始终可见；整体参考 Apple HIG 的层级、分组和克制动效，保留 Windows 的拖动、最大化和关闭保护。
- 新的桌面布局重构将设置分类、表单和快捷键监听统一呈现；笔记树为滚动条预留空间，草稿与笔记使用一致行高和克制的选中底色。
- 修复保存笔记跳回开头；保存及图片路径收归保留当前滚动位置、光标与撤销记录。
- 检查发现新版本后，导航栏版本号上方显示更新入口，进入已有下载与安装流程；不会自动覆盖正在运行的程序。

- 修复滚动时卡片被挤压、内容截断及缺少滚动条；设置、历史、学习表单和统计等视口使用一致的滚动容器，头部与操作区保持可见。
- 新增内置「草稿」目录，可保留多份草稿及图片资源；按份自动保存，切换与关闭等待末次输入落盘，保存或删除一份不会影响其他草稿。
- 图片云端设置按存储协议配置 Endpoint、Bucket、Region、凭据、前缀及寻址方式，提供后台连接检查和失败重试；不绑定特定厂商，密钥单独加密保存。
- 重构 Markdown 主题配置与对比度校正，改善表格、代码块和多层列表；笔记更多菜单打开时正文保持可见，悬停卡片随指针移动，目录拖动预览与源行等高。
- 空间管理区分已清理、失联与可清理副本，提供分类占用和统计时间；错误用可操作的说明呈现，保留外部原文件与历史。
- 设置中新增手动检查更新、下载校验及重启安装；按实际 EXE 位置替换，保留旧版，启动失败尝试回退。详见[更新方案](update-design.md)。

- 目录、子目录和笔记共用一个滚动区，折叠目录不关闭当前正文。默认主导航宽 160 像素、笔记库宽 280 像素，已有宽度继续保留。两栏均可拖至左缘隐藏，侧栏图标用于隐藏或恢复；宽度和显隐按资料库保存。
- 拖动分隔条只显示虚线候选位置，正文保持可见，松手才应用尺寸；Esc、失去焦点或鼠标捕获会取消。目录计数、学习状态、搜索和排序使用随资料更新的缓存，折叠目录不构造隐藏笔记行，减少拖动时的重复工作。
- 笔记库支持名称升降序、更新时间从新到旧或从旧到新，排序按资料库保存。绿色 **A** 表示新增且尚未记录学习，琥珀色 **M** 表示修改尚未记录学习；当前内容与已确认学习的版本一致时不显示醒目标记。外部文件显示「外部」标签，缺失文件显示「待定位」；悬停可查看副本或外部跟踪来源。
- 目录和笔记均可拖动分类，松手后才提交；紧凑预览保持在指针附近，有效目标悬停时突出显示。目录的重命名、移动、删除空目录和新建子目录位于右键或行尾菜单；新建和重命名支持 Enter 提交。
- 当前代码块右下角显示语言输入框，输入时提供候选，不支持的名称确认后清空。Tab / Shift+Tab 调整列表层级，Ctrl+1…6 / Ctrl+0 设置标题或段落。更改仅调整语言标记，保留代码内容、围栏和其他标记，支持撤销重做；只读内容不能修改。
- 浮动通知采用紧凑卡片、结果图标和颜色区分，在整个窗口顶部水平居中。相同通知可同时出现，最多显示两条，另外保留最近八条待显示结果；成功约 4 秒、失败约 8 秒后收起，悬停暂停倒计时，可逐条关闭，并有进入和退出动画。持续错误不会无限积压；通知不改变正文大小或接管输入焦点。
- 确认与目录表单使用窗口居中的弹窗，内容在限定高度内滚动；Tab / Shift+Tab 切换弹窗内焦点，Esc 取消返回，背景操作暂停。可操作控件使用手形指针，布局分隔条使用水平调宽指针。
- 设置分为「学习」「外观」「快捷键」「存储」「同步」「关于 / 账户」，分类内容独立滚动，保存与重置入口保持可见。切换分类保留同一份草稿；保存才原子发布整套配置，未保存离页、关闭或执行资料操作时可选择保存、放弃或继续编辑。恢复初始设置生成默认草稿，仍需保存。
- 应用和 Markdown 编辑命令支持直接按键录制、追加组合与清空绑定，Esc 取消录制；录制不触发原快捷操作。冲突涉及的各行实时标红并显示对应命令，解决后才能保存。重映射保留正文、选区与撤销历史。
- 参数通过 `config` crate 加载，学习、界面、外观、图片、快捷键和同步分类保存，初始配置文件与历史配置代保留。升级 `rustls-webpki` 至 0.103.16、`webpki-root-certs` 至 1.0.10，修复证书信任问题。

- 「＋」集中新建、导入文件与文件夹，排序与更多操作使用菜单；拖入外部文件时显示明确的「＋」接收区域。
- Markdown 图片支持读取、插入、粘贴与拖放，按笔记独立管理，文件名包含添加时间和笔记名；转为托管副本和保存时复制外部图片，源文件保留。可选择自定义本地目录、通用 S3 兼容对象存储或复用 WebDAV/NAS；云端模式保留本地缓存，失败保留暂存资源。
- 提供系统、亮色、暗色和命名自定义主题，统一原生界面与编辑器；外观预览、预设编辑及图片位置设置遵循同一套保存/放弃流程。
- 图片解析、下载、校验在后台运行，预览缓存有容量限制；通知宽高根据内容调整，支持多条、悬停暂停与退出动画。

分类操作只改变逻辑目录元数据，源文件和历史保留；目录最多八层，同级不能重名，删除目录要求没有笔记或子目录。移动目标继续排除当前目录、自身、子孙目录及超深位置，资料库切换后的过期拖放和菜单动作会被拒绝。已取消管理的笔记仍可调整分类。文件路径默认隐藏，可在设置中开启并保存；右键显示原文件和复制路径始终可用。

目录分类随数据库备份保存；界面等分类设置跟随资料库独立保存。**本版恢复数据库只恢复学习资料，保留当前设置**；完整迁移会复制分类配置。旧版数据库设置与 `sync-config.json` 首次启动时导入，原文件保留。连续 Markdown 编辑、语法高亮、历史和草稿机制沿用现有文档协议；继承 0.5.0 的 Windows 正文绘制与拆分 UTF-16 输入修复，并修复按钮与调宽光标切换的原生延迟。

Windows 10/11 x64，使用 GPUI Kit 0.7.3 和本地 WebView2 编辑面。需 Microsoft Edge WebView2 Runtime；编辑器资源离线打包，普通使用无需 Node.js。发布包名为 `WW-StudyApp-0.6.0-windows-x86_64.zip`，解压后运行 `WW-StudyApp.exe`。已有资料库、配置、同步目录和凭据标识继续沿用，开发构建仍使用 `studyapp.exe`。GPUI Windows 绘制层和组件补丁的完整修改源码、许可证及来源说明随包提供。

沿用 schema 3，兼容读取旧 schema 1/2。默认数据库位置仍为 `%APPDATA%\StudyApp\StudyApp\data\studyapp.sqlite3`，升级前可先导出备份。空间管理仍只允许逐份确认清理托管副本，历史和学习记录保留；外部源文件、未知文件及整个目录不会被删除。

笔记同步传输最新 Markdown，图片可独立使用 S3 兼容对象存储或复用 WebDAV/NAS；学习记录、复习计划、目录分类和完整历史仍在本地；微信登录和账户级云端仍为预留接口。ZIP 未代码签名；本版提供用户主动检查、下载和重启更新，校验安装包、识别当前安装位置并保留旧版。测试、原生验收和发布状态以 [验证记录](https://github.com/xwwpy/StudyApp/blob/main/docs/verification.md) 及对应 GitHub Release 为准。
