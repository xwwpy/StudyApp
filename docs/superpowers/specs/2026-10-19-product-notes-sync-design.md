# StudyApp 0.2：笔记创作与用户自有存储同步

用户授权持续迭代且免逐项审核；2026-10-19 明确选择 WebDAV + 本地文件夹/NAS。延续 Windows 原生 GPUI Kit、本地优先，不需要账号；微信和 S3 保留接口。当前 v0.1.0 的发布流程继续检查。

## 交付范围

1. 窗口接收多个 Markdown 文件拖入，拒绝无效类型并逐项反馈；与导入按钮走相同后台通道。允许拖入目录时仅导入其中 Markdown，限制深度/数量，不跟随目录链接，避免无限遍历。
2. 新建标准 Markdown 笔记，资料库托管于 notes/<UUID>.md；中文标题不作为路径，避免非法文件名。支持 Markdown 编辑、预览、Ctrl+S、自动保存草稿、显式保存并生成不可变版本。导入的外部文件仍保持只读，可复制为托管笔记。原文件的外部修改继续被观察。
3. 展示创建、修改、最近学习、上次与下次复习时间；支持正文搜索、按学习日期过滤记录、导出 Markdown 快照。自动记录编辑日期不自动宣称学习，学习日期仍来自确认的学习记录。
4. 配置一个同步目标：本地文件夹/NAS 或 HTTPS WebDAV（回环 HTTP 仅用于测试）。支持测试连接、手动同步、可选定时同步、最近结果、错误与冲突提示。始终保留本地资料；同步最新版 Markdown，版本历史/学习记录/复习计划仍由本地数据库和显式备份管理。
5. 同步专用目录使用 StudyApp/notes/<UUID>.md，忽略其他文件，不传播删除。导入笔记可以上传快照，但拉回内容不能覆盖外部原文件，应创建托管副本并说明来源。新远端文件成为本地托管笔记。
6. 三方比较本地、远端和上次同步状态。仅一端修改则更新另一端；两端修改时先保留本地冲突副本，再接收远端内容，不丢弃任一版本。远端写入采用条件请求；条件不满足重新比较，不能覆盖未知修改。失败不得推进同步基线。
7. WebDAV 凭据使用 Windows 当前用户保护存储，不能进入 SQLite、备份、日志或仓库；TLS 验证启用，禁止携带凭据跨域重定向；网络操作不阻塞学习计时和页面。

## 选择与取舍

推荐并采用“SQLite 历史 + 标准 Markdown 文件 + 可替换同步提供者”。仅文件夹镜像不能可靠记录学习与冲突；自建账号云服务需要部署和运维，超出本轮用户自有服务选择。WebDAV 和本地文件夹实现同一个列举/读取/条件写入接口，S3 后续实现该接口。

## 数据与失败规则

- 保持 0.1 数据库可读取，新增字段使用版本化迁移/默认值；恢复备份后托管路径必须落在当前资料库，禁止向备份携带的任意路径写入。
- 托管保存具备版本 CAS：编辑器打开时的哈希必须匹配，外部更改时保留草稿并提示冲突。成功状态必须代表快照与文件都已处理，文件/数据库任一步失败仍保留可恢复内容；禁止静默覆盖。
- 同步读取与响应有体积、文件数量和超时限制；拒绝路径穿越、不合法 UUID、非同源 WebDAV 地址和损坏编码。远端内容按照不可信 Markdown 处理。
- 同步后台基于快照执行网络操作，应用返回结果时再次验证本地预期版本。同步下行版本属于离线导入，不计入当前学习建议。
- 不删除用户文件，不清空同步目录。冲突副本可在应用中查看和再次编辑。

## 验收

- 核心测试：新建/保存/版本与日期、重启、保存冲突、导出不覆盖、旧库兼容、备份恢复路径、数据库/磁盘失败。
- 同步测试：两份独立资料库往返、本地改动、远端改动、双端冲突、重复同步、失败不推进、文件大小/路径限制；回环 HTTP WebDAV fixture 验证认证、PROPFIND、ETag 条件写入和错误。
- 原生窗口：拖入导入、新建编辑保存、草稿恢复/冲突提示、搜索、导出、同步设置和手动同步。
- 保持 fmt、Clippy、全部测试、安全检查；发布 0.2 Windows ZIP 并实际启动，CI/CD 对新版本成功执行。

正式产品成熟度以这些可验证能力为准，不宣称已经接入未配置的真实 WebDAV 账号、完成代码签名或微信登录。
